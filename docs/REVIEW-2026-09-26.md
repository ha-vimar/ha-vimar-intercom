# Full-repository review, 26 September 2026

On 26 September 2026 seven reviewers read the whole integration (SIP layer, media pipeline, HomeKit
layer, hub and setup, config flow and entities, security including git history, tests and docs). The
headline claims were then checked by hand, and C1 was reproduced on a running system. This page lists
every finding and what happened to it in 1.1.0. File references are to the code before the fixes.

Status: fixed, changed (fixed differently from the suggestion), or deferred (with the reason).

## Critical

| # | Finding | Status |
|---|---|---|
| C1 | Every `vimar_intercom.*` service failed after an entry reload with `'bool' object is not subscriptable`: HomeKit state lived in `hass.data[DOMAIN]` next to the entries, and the hub lookup took the first value. Services were never removed on unload for the same reason. | Fixed. HomeKit state moved to its own key; the lookup only accepts entries that have a hub. Verified live: service, reload, service again. |
| C2 | `fetch_local`: arbitrary file write and SIP digest sent to any host, callable by any user. | Fixed. Upstream 1.0.7 had already restricted the host to private addresses and the file name to a fixed folder; the service is now also administrator-only. |
| C3 | The QR payload (with the SIP password) and SRTP keys reached the debug buffer that any user could read. | Fixed. Upstream 1.0.7 dropped the QR log and made the buffer administrator-only; SRTP keys (`inline:` and parsed SDP dicts) are now masked in both logs. |

## Correctness

| # | Finding | Status |
|---|---|---|
| I1 | After a TLS drop the reader awaited its own reconnection, whose REGISTER answer only the reader delivers. | Fixed. The reader hands reconnection to a separate task and resumes on the new connection; concurrent reconnects share one attempt. Tested with a fake stream. |
| I2 | No SIP `CANCEL`: hanging up a ringing outgoing call only cleared flags. | Fixed. `CANCEL` reuses the INVITE's branch; a `200` that crosses it gets an `ACK` and a `BYE`. Verified live: `CANCEL`, `200`, `487`, `ACK`. |
| I3 | The reorder buffer kept late packets forever and its flush could walk the 16-bit space. | Fixed. `ReorderBuffer` drops late packets, jumps to the next present packet when full, and restarts on large jumps. |
| I4 | HomeKit `stop_stream` during `start_stream` closed sockets under a starting view and left a dead video sink. | Fixed. Per-session lock; every resource is recorded as soon as it exists; a start overtaken by a stop returns false. |
| I5 | Concurrent or cancelled teardowns leaked sockets. | Fixed. One close task per session, shielded from its callers' cancellation. |
| I6 | A late `call_ended` from the previous call damaged the new one. | Fixed. The hub ignores `call_ended` while another call is active; HomeKit's handler checks `calling` too. |
| I7 | A new view cancelled a hang-up that was already sending its BYE. | Fixed. The hang-up runs shielded; a new view waits for it and then calls again. |
| I8 | Early media on every INVITE, even during a call, replaced the call's SRTP keys. | Fixed. No early media while in a call or calling. |
| I9 | Early-media state leaked between calls; a `CANCEL` did not stop early media. | Fixed. |
| I10 | The talk direction's RTP clock ran ahead of real time. | Fixed after measuring it: 12.5 to 13.7 s of audio for 10 s of speech. A pacer sends one frame per 20 ms tick. |
| I11 | HomeKit audio depended on the internal `/av` ffmpeg's forwarding flag. | Fixed. |
| I12 | The HomeKit port pool was filled from an executor thread. | Fixed. Ports are reserved on the event loop; only the SDP file is written in the executor. |
| I13 | Unload and failed setup did not clean up. | Fixed. Unload hangs up and resets SIP state; setup that cannot reach the relay raises `ConfigEntryNotReady`. |
| I14 | Saving the detected model reloaded the integration. | Fixed. The update listener reloads only when the options change. |
| I15 | A transcoder started at an unanswered ring stayed allocated. | Fixed. New ring-ended hook; a dead transcoder is cleaned up before a new one starts. |
| I16 | `request_processor` stopped for good if a reply failed to send. | Fixed. |
| I17 | Route set not applied to ACK and INFO; BYE and CANCEL not matched to the dialog; re-INVITE treated as a ring. | Fixed. The 2xx ACK and INFO follow the route set; unknown-dialog BYE gets `481`; re-INVITE is answered with the current SDP. Verified live on the ACK. |

## Security

| # | Finding | Status |
|---|---|---|
| S1 | `/av` needed no authentication. | Fixed. Authentication required; Home Assistant's ffmpeg uses a signed loopback URL with Home Assistant's real port and scheme. The dead MJPEG `/video` view was removed. |
| S2 | A negative `Content-Length` from the relay spun the framer forever. | Fixed. Lengths outside 0 to 1 MB drop the stream. A lone CRLF pong no longer eats the next message. |
| S3 | Local UDP SIP accepted datagrams from anyone. | Fixed. Only the configured intercom. |
| S4 | Plain RTP accepted from anyone, and an injected SPS was persisted. | Fixed. Plain RTP only from the call's peer address; SRTP is authenticated by its key. |
| S5 | TLS verification off if the CA file was missing. | Changed. Upstream 1.0.7 already tries verification first and logs a warning when it falls back. Kept, because plants with other certificates would otherwise stop working. |
| S6 | Pin file mode, QR link after pairing, `compare_digest` on non-ASCII. | Fixed. |
| S7 | CR/LF injection into SIP from service and WebSocket input. | Fixed. Upstream 1.0.7 covered IDs and headers; full `sip:` URIs are now checked too. |
| S8 | `random` for SIP identifiers. | Fixed. `secrets`. |
| S9 | Services and WebSocket maintenance actions were not admin-gated. | Fixed for `send_command`, `fetch_local` and the WebSocket `command`, `register`, `probe`, `scan`, `reconnect`. Call, answer, hang up and open stay available to every user, as the door and camera entities are. |
| S10 | Tool session caches committed under `graft/`. | Fixed. Removed and ignored. |
| S11 | No secrets in history. | Nothing to do. |
